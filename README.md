# 💳 Caixa Eletrônico - Projeto em Java

Um simples sistema de **Caixa Eletrônico** desenvolvido em **Java**, com o objetivo de praticar **Programação Orientada a Objetos (POO)**, **uso de classes**, **métodos** e **controle de fluxo** no terminal.

---

## 🚀 Funcionalidades

- Cadastro de usuário com nome, tipo de conta e saldo inicial  
- Exibição de dados do usuário formatados  
- Menu interativo com as opções:
  - 💸 **Sacar valores** (com validação de saldo disponível)  
  - 💰 **Depositar valores**  
  - 📊 **Ver saldo atual formatado**  
  - ❌ **Sair do sistema**
- Limpeza automática da tela a cada operação  
- Tratamento básico de entradas do usuário  

---

## 🧠 Conceitos utilizados

- Programação Orientada a Objetos (POO)  
- Encapsulamento ( private, get, set)  
- Estruturas de repetição e decisão ( while, switch, if/else)  
- Manipulação de entrada de dados com Scanner  
- Formatação de valores monetários ( String.format)  
- Uso de "Locale" para permitir ponto e vírgula em números
